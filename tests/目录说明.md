# 自动化测试目录说明

## 目录目的

本目录承载后端重构后的自动化测试，不直接把现有顺序实验脚本当作测试。测试必须引用 `FR-*`、`BR-*`、`NFR-*`、`AC-*`、`API-*` 或 `ADR-*` 编号，并按风险分层。

## 预期分层

- `unit/`：输入校验、状态机、算法纯函数、数据转换和边界测试。
- `integration/`：SQLite、文件系统、任务编排、HFSSAdapter 测试替身和 HTTP 层。
- `contract/`：`openapi.yaml` schema、状态码、错误响应和兼容性。
- `e2e/`：关键用户流程、任务轮询、结果查看和下载。
- `fixtures/`：固定方向图、黄金算法结果、测试输入和最小 HFSSAdapter 响应。
- `evidence/`：运行报告由 CI 或任务产物生成；不提交大体积运行结果。

真实 HFSS 集成验收在服务器进行；开发机测试不得伪造真实 HFSS 通过。
