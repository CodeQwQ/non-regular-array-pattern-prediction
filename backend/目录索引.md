# 后端模块索引

| 文件 | 用途 | 主要类/函数 | 关联 |
|---|---|---|---|
| `__init__.py` | 包入口和版本 | `__version__` | ARCH |
| `config.py` | 环境配置、HFSS/预测模式和路径 | `Settings` | ADR-010、ALG-EQ-001 |
| `cleanup.py` | 三个月 temp/output 数据清理和独立进程 | `cleanup_expired`、`start_cleanup_process` | FR-004、EX-009 |
| `errors.py` | 统一错误和 HTTP 映射 | `AppError`、`error_response` | EX、API |
| `models.py` | 输入、项目、任务和结果数据模型 | `ArrayInput`、`Project`、`Task` | BR、API |
| `validation.py` | 输入标准化和业务校验 | `normalise_array_input`、`choose_authoritative_input` | BR-005～BR-007 |
| `storage.py` | SQLite 元数据和结果索引，原子登记已发布结果 | `SQLiteStore`、`save_result` | ADR-010、FR-003、NFR-003 |
| `hfss_adapter.py` | HFSSAdapter 协议和开发替身 | `HFSSAdapter`、`StubHFSSAdapter` | ADR-006、ADR-011 |
| `hfss_real_adapter.py` | 服务器延迟加载实验 HFSS 类和注入 runner | `RealHFSSAdapter` | TASK-HFSS-001 |
| `algorithm.py` | 可注入的预测算法接口和替身 | `PredictionEngine`、`StubPredictionEngine` | ALG-EQ-001 |
| `algorithm_reference.py` | 训练/测试阵列特征、ECP、虚拟阵列、Z 矩阵、cn 展开、总阵合成和方向图网格纯函数 | `generate_grid_array`、`calculate_unit_features`、`polarized_ecp`、`build_virtual_grid`、`build_zn`、`solve_cn`、`expand_cn_samples`、`synthesize_total_field`、`validate_pattern_records` | ALG-EQ-001 |
| `data_io.py` | 方向图、位置表、特征和 cn CSV fail-loud 适配 | `load_pattern_csv`、`load_position_table`、`load_feature_csv`、`load_cn_dataset` | ALG-EQ-001、FR-001～FR-003 |
| `model_adapter.py` | XGBoost cn 模型参数、输入校验、加载/训练/预测/保存 | `XGBoostParams`、`XGBoostCnModel` | ALG-EQ-001、FR-001 |
| `reference_engine.py` | 注入式模型→Z@cn→单元 ECP→总阵预测链路 | `ReferencePredictionEngine` | ALG-EQ-001、FR-003 |
| `task_manager.py` | 后台训练/评价任务、HFSS 状态检查、结果规范化与分支状态；结果采用临时目录发布并在提交失败时回滚 | `TaskManager`、`_run_training`、`_run_evaluation`、`_run_validation`、`_require_adapter_success`、`_normalise_result`、`_remove_result_path` | ADR-002～ADR-004、FR-003、AC-017、AC-025～AC-027 |
| `application.py` | API 应用组装和业务路由 | `Application` | API |
| `http_api.py` | 标准库 HTTP 服务和请求处理 | `create_server`、`RequestHandler` | API |
| `server.py` | 命令行启动入口 | `main` | NFR-006 |

## 关键数据流

```text
HTTP → Application → validation/storage/task_manager
                         ├─ PredictionEngine
                         └─ HFSSAdapter
```

所有公开函数必须说明参数、返回值和异常；修改行为时同步测试和追踪矩阵。
