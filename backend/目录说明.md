# 后端目录说明

本目录实现 `/api/v1` HTTP 接口、SQLite 状态存储、后台任务、输入校验、结果持久化、项目级磁盘日志和 HFSS/算法适配层。`hfss_runner.py` 将实验代码的关键训练、ECP 后处理、模型训练和验证流程封装为真实模式入口。

后端正式默认使用真实 HFSS 和参考预测模式。服务器依赖见根目录 `requirements-server.txt`。开发测试必须显式设置 `ARRAYLAB_HFSS_MODE=stub` 与 `ARRAYLAB_PREDICTOR_MODE=stub`。真实 COM 数值和工程加载由服务器验收；关键算法由黄金夹具和服务器数据复核。

运行：

```text
py -3.12 -m backend.server
```

默认监听 `127.0.0.1:8000`。可用环境变量覆盖 `ARRAYLAB_HOST`、`ARRAYLAB_PORT`、`ARRAYLAB_DB_PATH`、`ARRAYLAB_DATA_ROOT`、`ARRAYLAB_HFSS_MODE`、`ARRAYLAB_PREDICTOR_MODE`、`ARRAYLAB_AVERAGE_PATTERN_PATH`、`ARRAYLAB_MODEL_PATH`、`ARRAYLAB_HFSS_MODULE_PATH`、`ARRAYLAB_HFSS_RUNNER_MODULE_PATH`、`ARRAYLAB_CLEANUP_ENABLED` 和 `ARRAYLAB_RETENTION_DAYS`。正式模式默认加载仓库内的 `hfss_runner.py`，训练完成后自动把 runner 返回的模型和平均 ECP 安装为参考预测引擎；只有显式配置外部 runner 时才覆盖该默认实现。生产清理通过 `ARRAYLAB_CLEANUP_ENABLED=1` 启用。
