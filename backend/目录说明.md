# 后端目录说明

本目录实现 `/api/v1` HTTP 接口、SQLite 状态存储、后台任务、输入校验、结果持久化和可注入的 HFSS/算法适配层。

后端默认使用开发替身运行，不代表真实 HFSS 或最终算法已经通过。真实 HFSS 由服务器验收；关键算法由黄金夹具和审查 Agent 验证。

运行：

```text
py -3.12 -m backend.server
```

默认监听 `127.0.0.1:8000`。可用环境变量覆盖 `ARRAYLAB_HOST`、`ARRAYLAB_PORT`、`ARRAYLAB_DB_PATH`、`ARRAYLAB_DATA_ROOT`、`ARRAYLAB_HFSS_MODE`、`ARRAYLAB_PREDICTOR_MODE`、`ARRAYLAB_AVERAGE_PATTERN_PATH` 和 `ARRAYLAB_MODEL_PATH`。`reference` 模式必须同时提供平均 ECP 和模型文件，否则明确失败。
