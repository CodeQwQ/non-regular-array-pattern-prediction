# 前端目录说明

本目录是正式前端实现的起点。它使用 Vue 3 + Vite，通过 `/api/v1` 与后端通信，页面状态来自真实项目/任务/结果接口。

正式前端不得保留 `UI.html` 中的硬编码项目、固定 HFSS 路径、演示任务、假图表数据、演示 Blob 下载或训练/评价 `setTimeout` 模拟流程。浏览器页面使用文本方式接收 API-001 规定的本机绝对 `.aedt` 路径，并支持手工位置表、JSON 文件和 JSON 文本输入，JSON 同时存在时优先使用 JSON；复杂校验由后端完成。`frontend/e2e/` 使用本地 stub 后端验证真实 API 驱动流程，不能代替服务器 HFSS 验收。

运行：

```text
npm install
npm run dev
```
